# Host a CoA server for other players

**Portable characters are experimental.** The feature is in active development and may contain bugs.

Draft for owner review — Manager 0.7.0 preview.

## Set up your server

1. Choose **Host a server** on the welcome screen.
2. Choose **Install new server**, or **I already have a server**.
3. Finish setup, then start the server from **Overview**.
4. Link your game client and test joining your server yourself.

## Play with friends

Open **Play with friends**. Use the LAN/private-network instructions for your connection method and run the connectivity checks. Your computer and server must stay on while friends play. Share the connection information prepared by the Manager, never database credentials.

## Let other players find your realm

1. Open **Settings**, then find **Public listing**.
2. Fill in a clear realm name, a short description, language and region.
3. Review the join/account options and connection route.
4. Publish when you are ready to accept players.
5. Check that the realm appears in the browser and ask a friend to test joining from another connection.

A listing makes your server discoverable; it does not move hosting to the cloud or guarantee that your network can be reached. If joining fails, use the connection checks before changing router settings. Portable characters also require a compatible server build and its required settings.

Use **Backups** before changing server versions or optional modules. To stop accepting visitors, turn off the listing; to stop hosting, stop the server.
