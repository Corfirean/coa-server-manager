# Héberger un serveur CoA pour d'autres joueurs

[English](../HOST-A-SERVER.md) · [Русский](../ru/HOST-A-SERVER.md) · [Deutsch](../de/HOST-A-SERVER.md) · **Français** · [Español](../es/HOST-A-SERVER.md) · [简体中文](../zh-CN/HOST-A-SERVER.md)

**Les personnages portables sont expérimentaux.** Cette fonction est encore en développement et peut présenter des bugs.

## Préparer le serveur

1. Sur l'écran d'accueil, choisissez **Héberger un serveur (Host a server)**.
2. Choisissez **Installer un nouveau serveur (Install new server)** ou indiquez votre serveur existant avec **I already have a server**.
3. Terminez l'installation puis démarrez le serveur dans **Vue d'ensemble (Overview)**.
4. Associez votre client de jeu et vérifiez d'abord que vous pouvez vous connecter vous-même.

## Inviter des amis

Ouvrez **Jouer avec des amis (Play with friends)**. Suivez les instructions correspondant à votre réseau local ou privé et lancez les tests de connexion. Votre ordinateur et le serveur doivent rester allumés pendant que vos amis jouent. Partagez les informations de connexion préparées par le Manager, jamais les identifiants de la base de données.

## Rendre le royaume visible dans le catalogue

1. Dans **Paramètres (Settings)**, trouvez **Public listing**.
2. Renseignez un nom clair, une brève description, la langue et la région.
3. Vérifiez les options de connexion et de compte ainsi que le chemin réseau utilisé.
4. Publiez l'annonce lorsque vous êtes prêt à accueillir des joueurs.
5. Vérifiez sa présence dans le navigateur de royaumes et demandez à un ami de tester l'accès depuis une autre connexion.

L'annonce rend votre serveur visible ; elle ne l'héberge pas dans le cloud et ne garantit pas que votre réseau soit accessible. En cas d'échec, utilisez les tests de connexion avant de modifier le routeur. Les personnages portables nécessitent aussi une version serveur compatible et les réglages requis.

Créez une **sauvegarde (Backups)** avant de changer de version serveur ou de modules. Désactivez l'annonce pour retirer le royaume du catalogue ; arrêtez le serveur pour cesser de l'héberger.
