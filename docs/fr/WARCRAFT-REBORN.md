# Warcraft Reborn

[English](../WARCRAFT-REBORN.md) · [Русский](../ru/WARCRAFT-REBORN.md) · [Deutsch](../de/WARCRAFT-REBORN.md) · **Français** · [Español](../es/WARCRAFT-REBORN.md) · [简体中文](../zh-CN/WARCRAFT-REBORN.md)

Choisissez **Warcraft Reborn** dans **Vue d'ensemble (Overview)** pour créer ce royaume ou y passer. Votre version serveur doit le prendre en charge ; une version incompatible est refusée avant la création des bases. Fermez le client avant de changer pour mettre immédiatement à jour son royaume enregistré.

Les comptes sont communs avec les autres royaumes locaux. Warcraft Reborn possède ses propres personnages : changer de profil ne copie ni personnages ni progression.

Les bots ne sont pas disponibles sur Warcraft Reborn. Les autres modules optionnels sont expérimentaux. Le transfert de personnages portables vers Warcraft Reborn n'est pas encore pris en charge. **Les personnages portables restent expérimentaux.**

Sauvegardes et mises à jour couvrent tous les royaumes créés. Vérifiez le royaume indiqué sur le point de restauration avant de restaurer.

Le démarrage simultané concerne uniquement CoA et Wildcard. Désactivez **Start CoA and Wildcard together** dans **Paramètres (Settings)** avant de sélectionner Warcraft Reborn.
