# 为其他玩家搭建 CoA 服务器

[English](../HOST-A-SERVER.md) · [Русский](../ru/HOST-A-SERVER.md) · [Deutsch](../de/HOST-A-SERVER.md) · [Français](../fr/HOST-A-SERVER.md) · [Español](../es/HOST-A-SERVER.md) · **简体中文**

**便携角色是一项实验性功能。** 目前仍在开发中，使用时可能遇到问题。

## 准备服务器

1. 在欢迎页面选择**我要搭建服务器（Host a server）**。
2. 选择**安装全新服务器（Install new server）**；如果已经安装，选择 **I already have a server** 并指定现有目录。
3. 完成设置后，在**概览（Overview）**中启动服务器。
4. 关联游戏客户端，先自行测试能否进入游戏。

## 邀请朋友

打开**好友联机（Play with friends）**，按照所用连接方式完成局域网或私有网络设置，并运行连接检查。朋友游玩期间，你的电脑和服务器都必须保持开启。分享管理器准备的连接信息即可，不要分享数据库账号和密码。

## 将服务器加入公开列表

1. 打开**设置（Settings）**，找到 **Public listing**。
2. 填写清楚的服务器名称、简短介绍、语言和地区。
3. 检查加入方式、账号选项和连接路径。
4. 准备好接待玩家后，发布服务器信息。
5. 确认它出现在服务器列表中，并请朋友使用另一条网络连接测试能否加入。

公开列表让玩家能够找到你的服务器，但不会把服务器搬到云端，也不能保证你的网络一定可达。如果无法加入，请先运行连接检查，再考虑调整路由器。使用便携角色还需要兼容的服务端版本和必要设置。

更换服务端版本或调整可选模块前，请先在**备份（Backups）**中创建备份。关闭公开信息即可从列表中撤下服务器；要结束托管，请停止服务器。
