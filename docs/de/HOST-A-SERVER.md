# Einen CoA-Server für andere Spieler hosten

[English](../HOST-A-SERVER.md) · [Русский](../ru/HOST-A-SERVER.md) · **Deutsch** · [Français](../fr/HOST-A-SERVER.md) · [Español](../es/HOST-A-SERVER.md) · [简体中文](../zh-CN/HOST-A-SERVER.md)

**Portable Characters sind experimentell.** Die Funktion wird noch entwickelt und kann Fehler enthalten.

## Den Server einrichten

1. Wähle auf der Startseite **Einen Server hosten (Host a server)**.
2. Wähle **Neuen Server installieren (Install new server)** oder binde einen vorhandenen Server über **I already have a server** ein.
3. Schließe die Einrichtung ab und starte den Server unter **Übersicht (Overview)**.
4. Verknüpfe deinen Spielclient und prüfe zuerst selbst, ob du beitreten kannst.

## Freunde einladen

Öffne **Mit Freunden spielen (Play with friends)**. Folge der Anleitung für deine LAN- oder private Netzwerkverbindung und führe die Erreichbarkeitsprüfungen aus. Dein Computer und der Server müssen eingeschaltet bleiben, solange Freunde spielen. Teile die vom Manager vorbereiteten Verbindungsdaten, niemals Datenbank-Zugangsdaten.

## Deinen Realm öffentlich listen

1. Öffne **Einstellungen (Settings)** und suche **Public listing**.
2. Trage einen verständlichen Realm-Namen, eine kurze Beschreibung, Sprache und Region ein.
3. Prüfe die Beitritts- und Kontooptionen sowie den Verbindungsweg.
4. Veröffentliche den Eintrag, sobald du Spieler aufnehmen möchtest.
5. Prüfe, ob der Realm im Browser erscheint, und bitte einen Freund, von einem anderen Anschluss aus beizutreten.

Der Eintrag macht deinen Server auffindbar. Er verlagert ihn nicht in die Cloud und garantiert keine erreichbare Netzwerkverbindung. Wenn der Beitritt fehlschlägt, nutze zuerst die Verbindungstests, bevor du Routereinstellungen änderst. Portable Characters benötigen außerdem einen kompatiblen Server und die dafür erforderlichen Einstellungen.

Erstelle unter **Sicherungen (Backups)** eine Sicherung, bevor du Serverversion oder Zusatzmodule änderst. Um keine neuen Besucher mehr über den Katalog zu empfangen, deaktiviere den Eintrag. Um das Hosting zu beenden, stoppe den Server.
