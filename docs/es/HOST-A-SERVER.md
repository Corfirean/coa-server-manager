# Alojar un servidor CoA para otros jugadores

[English](../HOST-A-SERVER.md) · [Русский](../ru/HOST-A-SERVER.md) · [Deutsch](../de/HOST-A-SERVER.md) · [Français](../fr/HOST-A-SERVER.md) · **Español** · [简体中文](../zh-CN/HOST-A-SERVER.md)

**Los personajes portátiles son experimentales.** La función sigue en desarrollo y puede tener errores.

## Prepara el servidor

1. En la pantalla de bienvenida, elige **Alojar un servidor (Host a server)**.
2. Elige **Instalar un servidor nuevo (Install new server)** o indica el que ya tengas con **I already have a server**.
3. Termina la configuración e inicia el servidor desde **Resumen (Overview)**.
4. Vincula el cliente de juego y comprueba primero que tú puedes entrar.

## Invita a tus amigos

Abre **Jugar con amigos (Play with friends)**. Sigue las instrucciones para tu tipo de conexión LAN o red privada y ejecuta las comprobaciones de acceso. El ordenador y el servidor deben seguir encendidos mientras tus amigos juegan. Comparte los datos de conexión que prepara el Manager, nunca las credenciales de la base de datos.

## Publica el reino en el catálogo

1. En **Ajustes (Settings)**, busca **Public listing**.
2. Escribe un nombre claro, una descripción breve, el idioma y la región.
3. Revisa las opciones de acceso y de cuentas, además de la ruta de conexión.
4. Publica el reino cuando estés listo para recibir jugadores.
5. Comprueba que aparece en el buscador y pide a un amigo que intente entrar desde otra conexión.

Publicarlo permite que otros lo encuentren; no traslada el servidor a la nube ni garantiza que tu red sea accesible. Si no pueden entrar, utiliza primero las comprobaciones de conexión antes de tocar el router. Los personajes portátiles también necesitan un servidor compatible y los ajustes requeridos.

Crea una **copia de seguridad (Backups)** antes de cambiar de versión o de módulos. Desactiva la publicación para quitar el reino del catálogo; detén el servidor para dejar de alojarlo.
