# Actualizaciones, copias de seguridad y reparación

[English](../REPAIR_AND_REALMS.md) · [Русский](../ru/REPAIR_AND_REALMS.md) · [Deutsch](../de/REPAIR_AND_REALMS.md) · [Français](../fr/REPAIR_AND_REALMS.md) · **Español** · [简体中文](../zh-CN/REPAIR_AND_REALMS.md)

## Actualiza el servidor

Selecciona tu servidor en el Manager. Cuando haya una actualización, pulsa **UPDATE** y sigue las instrucciones. Deja la aplicación abierta hasta que termine: detendrá el servidor, creará un punto de restauración y comprobará el servidor actualizado.

Se conservan cuentas, personajes y ajustes. Las actualizaciones cubren todos los reinos creados. Si algo falla, lee el mensaje antes de volver a intentarlo; los datos de recuperación siguen disponibles en el Manager.

## Guarda una copia

Antes de hacer cambios importantes, usa **Copias de seguridad (Backups)** para guardar personajes, cuentas y ajustes. Las copias completas incluyen también el mundo. Comprueba a qué reino corresponde el punto de restauración y detén el servidor antes de restaurarlo.

Las versiones guardadas de personajes portátiles no sustituyen las copias del servidor. **Los personajes portátiles son experimentales.**

## Comprueba o repara la instalación

1. Detén el servidor.
2. En **Ajustes (Settings)**, ejecuta **Check files and database**.
3. Revisa el resultado. Si hay que restaurar archivos oficiales del servidor, elige **Repair** y sigue las instrucciones.

La reparación crea una copia de recuperación y restaura archivos oficiales conservando ajustes y bases de jugadores. Puede requerir que la versión instalada coincida con el paquete firmado publicado actualmente. Los datos de jugadores perdidos necesitan una copia; algunos problemas de base requieren una actualización correctiva del servidor.

Si una operación sigue bloqueada o vuelve a fallar, usa **Informar de un problema (Report a problem)** y adjunta el diagnóstico y el mensaje. No borres bases ni registros de recuperación para quitar un bloqueo.

## Ejecuta CoA y Wildcard a la vez

En **Ajustes**, activa **Start CoA and Wildcard together**. Los reinos comparten cuentas, pero mantienen personajes y mundos separados. En Resumen se muestra el estado de ambos y la parada detiene los dos.

Si habías configurado la red para amigos antes de activar el segundo reino, repite la configuración para que ambos sean accesibles. Desactiva el inicio simultáneo antes de cambiar a Warcraft Reborn.
