title: Modules Preview installs the bare modular core and copies classic servers instead of converting them
---
A new server installed by the Modules Preview goes straight on to the modular core and compiles no
module; modules are added later from the Modules page. Choosing an existing server with the classic
core no longer adds it as it is: a modular server is installed next to it and its accounts, characters,
world, bots and module settings are copied into it. The old server is only read and keeps working.
